\subsubsection*{両面リーのみ}

両面先制立直はリーのみでもほぼ正解。といっても、下記の３つの条件を全て満たしたら聴牌を外してもいい：

\begin{enumerate}
\item 早巡（6巡目以前）
\item 一つのブロックを落とすと打点上昇が見込む
\item 他の形からブロックを作りやすい
\end{enumerate}

手牌 \ref{mj:2-4-0} から \ref{mj:2-4-2} までは全て早めの両面リーのみ。打点はただの1300。手牌~\ref{mj:2-4-0} と~\ref{mj:2-4-1} は \mj{33z} を落としたらタンヤオや三色やピンフで打点は大きく上昇するため、速度を遅らせる価値がある。一方、\ref{mj:2-4-2} が \mj{6p} 単騎になる可能性があるので、それを避けて即リーがおすすめ\citep[][pp. 68--73]{tetsusenryaku}。

\subsubsection*{3飜40符の手牌}

3飜40符（ダマで5200、立直で満貫）なら表~\ref{tab:ev-gukei-riichi} によると統計的には微差。立直による打点上昇は概ね5200 $\rightarrow$ 8000だけ、もっと高い点数を得るためにもう両飜が必要なので12000になる確率は著しく低い。つまり、打点の上昇幅は現実的に2800だけ。こんな低い上昇幅は立直による損失リスク（アガリ率の下落と追いかけられ立直に放銃）に近いので、5200の立直判断は場況、良形変化の枚数、河などの要因に左右されやすい。

\citet{yoteru-5200riichi} によると、

\begin{itemize}
  \item 待ちがいいなら立直
  \begin{itemize}
    \item カン2、カン8、または両方28の双碰待ち
    \item 么九牌含みの双碰待ち（一方が中張牌でも可）
    \item 筋引っ掛け
  \end{itemize}
  \item 手替わりがないなら立直
  \item 待ちが一枚切られているならダマ
  \begin{itemize}
    \item ツモりづらい
    \item 待ちを切っている相手にとって使いづらいのでもう一回切ってくる確率が高いので、立直すると待ちが出る確率が激減する
    \item 現物待ち
  \end{itemize}
  \item 待ちの色が安いならダマ
\end{itemize}

待ちがいいが場況が安い場合は、統計的に立直が微差で優位なので基本的に立直する。

手牌~\ref{mj:5200-1} のように待ちが尖張牌の場合はダマ推奨 \citep[][p.~28]{miinin-stat}。\ref{mj:5200-2} のように待ちが28になると立直推奨。ソーズが安いでも基本的に立直推奨 \citep{yoteru-5200riichi}。

\tehai{112233m 22789p 68s}[東1局　南家　8巡目　ドラ \mj{2m}][5200-1]

\tehai{334405m 40588p 13s}[ドラなし][5200-2]

手牌~\ref{mj:5200-3} のように嵌張が手役に直結する場合、手替わりがないので、\citep{yoteru-5200riichi} によると立直推奨。逆に、同じ手役に絡む嵌張待ちの~\ref{mj:5200-4} は \citep[][pp.~149--150]{ooi-gundou} によるとダマ推奨。\ref{mj:5200-4} の場合、巡目が遅いのでダマ優位になる。1段目の早い巡目や点数が欲しい状況なら立直もアリ。

\tehai{12346789m 505p 22s}[ドラなし][5200-3]

\tehai{22567m 57p 234567s}[北家　11巡目　ドラ \mj{9s}][5200-4]

手替わりがあっても、内嵌張のように両面変化が2種類だけという少ない手替わりなら場況によって決める。よって、\ref{mj:5200-5} は平面的にどっちでもいいが、カン \mj{5p} が中筋となるなどの場況が入ってくると立直、逆に中筋ではない場合やピンズがやすい場合ならダマ \citep{yoteru-5200riichi}。

\tehai{234067m 46p 34077s}[ドラなし][5200-5]

\tehai{567m 07p 344056 88s}[南家　7巡目　ドラ \mj{1p}][5200-6]

\subsubsection*{役なし尖張牌双碰も曲げるか}

役なしの手牌なら、出アガリできないのでダマのメリットは良形変化と打点上昇だけ。立直のメリット（打点上昇と他家の足止め）が減らないので、自己都合で曲げることになりやすい。尖張牌双碰の場合は、4種類の良形変化と前述した立直のメリットの比較になる。変化するまで巡目がかかるので、比較は巡目に左右されやすい。結論からいうと、

\begin{itemize}
  \item 2段目前半まで
  \begin{itemize}
    \item 1300はダマ
    \item 2600以上はどっちでもいい\footnote{NAGAによる\href{https://naga.dmv.nico/htmls/8c2bd4b5841cb6cca44af62408bb00cdfd4165fd26776691a9ee891d767e8d80v2_2.html?tw=2}{西家4巡目ドラ2}と\href{https://naga.dmv.nico/htmls/d44d3e0059c563ff373cf9e4123c46e4fd66bcbb8cde386a935d8d96e6e041c9v2_2.html?tw=2}{西家8巡目ドラ2}と\href{https://naga.dmv.nico/htmls/dfbfd7e6d647892ceb0c9803245896534697d58598d4446fb26bf48b60986b93v2_2.html?tw=1}{南家5巡目ドラ3}のシミュレーション。}
  \end{itemize}
  \item 2段目後半なら立直
  \item 3段目なら形聴として取ってもいい
\end{itemize}

ピンフやタンヤオになりやすい牌姿なら1段目で尖張牌双碰を曲げることはない。\ref{mj:midshanpon-1} は \mj{35p46s} だけではなく \mj{4m} でタンヤオがつくので5種類の変化はドラ1でも曲げない\footnote{\href{https://naga.dmv.nico/htmls/b54aa3ab3415c25091503f7538d5f4392f8dd8f81f07cf08f1a3215906ad76adv2_2.html?tw=1}{NAGAのシミュレーション。}}。

\tehai{123678m 44678p 55s}[南家　4巡目　ドラ \mj{6p}][midshanpon-1]

手牌~\ref{mj:midshanpon-2} のようにピンフとタンヤオにならないならちょっと立直によるが、1段目の尖張牌双碰はやはり曲げない\footnote{\href{https://naga.dmv.nico/htmls/8c2bd4b5841cb6cca44af62408bb00cdfd4165fd26776691a9ee891d767e8d80v2_2.html?tw=1}{NAGAのシミュレーション。}オメガは立直するが他のヘビはしない。}。

\tehai{111678m 44678p 55s}[南家　4巡目　ドラ \mj{6p}][midshanpon-2]

2段目に入ると巡目が深いほどNAGAが立直したい。8巡目はまだダマしたい\footnote{\href{https://naga.dmv.nico/htmls/d44d3e0059c563ff373cf9e4123c46e4fd66bcbb8cde386a935d8d96e6e041c9v2_2.html?tw=1}{NAGAのシミュレーション。}}が、10巡目になると立直したいとなった\footnote{\href{https://naga.dmv.nico/htmls/dfbfd7e6d647892ceb0c9803245896534697d58598d4446fb26bf48b60986b93v2_2.html?tw=3}{NAGAのシミュレーション。}}。


\subsubsection*{愚形のみ手}

愚形リーのみは打つべきか否か、場況や待ちによっても諸説ある。

\begin{itemize}
  \item 打つべき場面
  \begin{itemize}
    \item 自分が親 \multicitep{rb1, p.~165; mark2-gukeiriichi}
    \item 筋待ち・1289待ち \citep[][p. 30]{miinin-stat}
    \item 5待ち・赤受けある \citep[][pp.~31--32]{ishibashi-black}

\subsubsection*{「双碰不如一嵌」} 

「双碰は嵌張にしかず」とは古来の戦術。嵌張待ちは誰かが3枚持っていてもまだ1枚が残っているから、対死（トイスー）の可能性がある双碰より良い、と考える。だが、同じ無筋で、残り枚数も同じ、手役に絡まない場合、後筋になる確率と待ち種類を考えると\textbf{双碰の方が有利}\citep{tsukemai}。残り枚数が多いの方と筋になっている方を選ぶのは基本。


\subsubsection*{ノベタンとドラ字牌単騎} 

\textbf{ドラ字牌単騎にする}\citep[][pp.~75--76]{miinin-choice}。ノベタンの方がアガリやすいが、ドラ字牌単騎は生牌でも期待値がより高い。


\subsubsection*{ツモり四暗刻}

\textbf{双碰待ちの四暗刻はダマ}\citep[][pp.~179--180]{miinin-choice}。立直してもツモ率が17\%から20\%までしか上がらないので。けれど、点数差がひどい状況なら立直する。
