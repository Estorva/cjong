\subfilepreamble{立直対応}

麻雀は（四麻の場合）自分以外の相手は3人いる。つまり、平均で言うと、自分が4回の中に1回後手を取る。どの姿勢で立直を受けるのは、上達するために欠かない技術。他家が立直と発声するあと、自分が牌をツモって、選択肢は下記のように、

\begin{itemize}
  \item 聴牌になる場合
  \begin{itemize}
    \item 追いかけ立直
    \item ダマ
    \item 聴牌外し・回し打ち
    \item ベタオリ
  \end{itemize}
  \item 聴牌にならない場合
  \begin{itemize}
    \item 向聴押し
    \item ベタオリ
  \end{itemize}
\end{itemize}

そして選択の基準は下記の色んな要素からなる、

\begin{itemize}
  \item 相手は親か子か
  \item 自分は面前か副露手か
  \item 自分の待ちは良形か愚形か
  \item 自分の手牌の価値
  \item 安牌の枚数
  \item 切る牌の危険度
  \item 通った筋の数
  \item 他家の動き
  \item 点棒状況
\end{itemize}

「ベタオリ」というのは安牌が複数枚の前提で成立する。安牌がたくさんあるならベタオリが成功する確率が高い。一方、安牌がないなら、どうせどっちの牌を切っても放銃のリスクがあるなら、聴牌で勝負する、という意見も。

データによると、\textbf{子が子の立直に対してベタオリの局収支は$-1100$点}\citep[][p. 83]{miinin-stat}、\textbf{子が親のリーチに対してベタオリの局収支は$-1700$点、親が子のリーチに対してベタオリの局収支も$-1700$点}\citep[][p. 84]{miinin-stat}。よって、立直に対して局収支はそれらの状況でそれらの数値より高いなら全部押す。

\subsubsection*{2軒立直に対する}

\textbf{ピンフのみでも追いかける}\citep[][pp.~151--152]{miinin-choice}。子の2人が立直してベタオリの局収支は$-$900、ピンフのみで追いかける局収支は$-700$、いずれにせよ損なので追いかける方がマシ。

と言うものの、立体図~\ref{rittai:niken} は自分がトップ目で、捨て牌濃厚な上家と下家の一発巡目に対して、ピンフのみでドラマタギの \mj{7s} が押せるかという問題。\citet[pp.~178--181]{doi} によるとこれは流石に押しすぎ。\mj{7s} 以外の打牌候補は、

\begin{itemize}
\item \mj{2m}：下家の現物、上家の筋、上家の双碰・単騎・嵌張にしか刺さらない
\item \mj{3m}：下家と上家の筋、双碰・単騎・辺張・嵌張にしか刺さらない
\item \mj{9p}：下家と上家の筋、双碰・単騎にしか刺さらない
\end{itemize}

安全度から見ると \mj{2m} と \mj{9p} が同じレベルだが、七対子の可能性も考えると \mj{9p} の方が少し危険。それに、\mj{9p} を切った後ヘッドレスになるので復活するとき聴牌の質は保証されない。よって、ここは打 \mj{2m}。上家が \mj{23s}、下家が \mj{68p} の搭子を落としたので、筋の \mj{3m} もかなり愚形に刺さりづらい。後でドラ \mj{6s} を引いたら追いかけてトップを大きく引き寄せる。

\subsubsection*{ダマ・副露}

全ての状況で両面ダマの局収支は両面立直より著しく低い\citep[][p. 92]{miinin-stat}。役があってもがんがんと立直をかけよう。

両面副露手で立直に対してがんがんと押すのはどうでしょう。表~\ref{tab:ev-ryanmen-furo} によると、多くの場合では押せる。ベタオリすべきな場合は子で親の立直に対して1飜だけの副露手。

また、\citet{doi}によると、2飜以下は押せない。3飜なら25・58まで押せる。3飜の36・47待ちは押せない。

\subsubsection{序中盤・副露手}

立体図~\ref{rittai:cheap-tenpai} の通り、自分が1000点の聴牌。通ってない筋は \mj{3m}--\mj{6m}--\mj{9m}、\mj{1p}--\mj{4p}--\mj{7p}、\mj{2s}--\mj{5s}--\mj{8s} と \mj{4s}--\mj{7s}。ツモ (1) \mj{3m} (2) \mj{2s} (3) \mj{5s} (4) \mj{9m} ならどうするか、という課題。対面の河による通っていない筋を分析すると\citep[][pp.~128--133]{tetsuoshi}、

\begin{itemize}
\item \mj{36m}：立直前に切られているので他の筋より少しマシ
\item \mj{47s}：\mj{6s} が3枚見えるので他の筋より少しマシ\footnote{\citet[p.~132]{tetsuoshi}によると \mjfn{6s} も立直前に切られているが、実際にその \mjfn{6s} は南家の河に写っていない。}

\item \mj{147p25s}：特に危険
\end{itemize}

ここまでの話は安牌と10\%牌に基づく。空間が少ないため全ての場合を挙げるのは不可能。ですが、内挿（ないそう）・外挿（がいそう）によると5\%牌と15\%牌の局収支を補足できる。例え、表~\ref{tab:ev-ryanmen-chase}を参照して、手牌\ref{mj:3-stat-1}から \mj{4p} （15\%牌）を切って立直する局収支は$-1300 + (-1300 - (-600)) / 2 = -1650$。ベタオリの局収支（$-1700$）と大差がないので、場況（点数状況・待ち枚数など）によって判断する\citep[][pp. 93--95]{miinin-stat}。

まだ、先制者の河に通っている筋の本数が多ければ他家の切れる牌も多く、ゲンバリの意味が薄くなる。こうなら追いかけ立直だ\citep[][p.~81]{doi}。

立体図~\ref{rittai:niken-genbari} は2軒立直のゲンバリ。ダマに寄る要素と立直に寄る要素を列挙すると、

\begin{itemize}
  \item 立直に寄る
  \begin{itemize}
    \item ピンフ・ドラ1は立直による打点効率が高い
    \item 下家が \mj{25s} を持っていなさそう
  \end{itemize}
  \item ダマに寄る
  \begin{itemize}
    \item ゲンバリ
  \end{itemize}
\end{itemize}

ゲンバリが有効なのは（1）他家が現物を持っていて、（2）安牌に困るときに切ってくる。今回下家から \mj{1s} が早めに出ていて、\mj{6'07s} の仕掛けも入っていて、周りの \mj{25s} が持っている確率は低いと推測できる。つまり、\mj{25s} が現物といっても、下家から出てくるのは期待できない。ゲンバリの効果が薄くなる上、打点効率が高い2000なら、立直にするのが正着。打点効率がそこまで良くないドラ0やドラ3ならダマもあり\citep[][pp.~146--149]{doi}。

\subsubsection*{壁か暗刻落としか}
