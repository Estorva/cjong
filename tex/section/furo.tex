\subfilepreamble{副露判断}

副露は、チー、ポン、カン、3種類の鳴きを指す。麻雀においては、仕掛けが入ると「門前」の状態が消えて、立直ができない。一発や裏ドラなど立直に関わる役もできない。そのため、副露手の打点の期待値は必ず門前手より低い。そして副露の部分は捨てないので、門前より捨てられる牌が少なくて、立直がかかっているとき安牌の枚数の期待値も門前より少ない。表~\ref{tab:naki-compare} の通り、副露のメリットは速度、そして役の確定。

\begin{table}[ht]
  \centering
  \begin{tabular}{lll}
    & 鳴き & 門前 \\
    \hline
    速度 & $\bigcirc$ & $\times$ \\
    打点 & $\times$ & $\bigcirc$ \\
    守備 & $\times$ & $\bigcirc$
  \end{tabular}
  \caption{鳴きのメリットとデメリット\citep[][p.~87]{hirasawa-naki}}
  \label{tab:naki-compare}
\end{table}

副露の基準は下記の諸要素の比較に基づく、

\begin{itemize}
  \item 手牌の速度がどれくらい早くなるか
  \begin{itemize}
    \item 「面前でいけそう」か
    \item 鳴く部分が急所（愚形）か
    \item 残る形がどうか、一向聴か両向聴か
    \item 早そうな他家がいるか
  \end{itemize}
  \item 手牌を短くすることに伴うリスクはどれくらいか
  \item （アガリトップなどアガる自体の価値が高い場面以外で）副露して打点がどれくらい下がるか
  \item 副露の部分が警戒されやすいか
  \item 巡目
  \begin{itemize}
    \item 巡目がまだ早いなら変化を見た
    \item 巡目が遅いなら形聴を取るためにも鳴きによる
  \end{itemize}
\end{itemize}

細かい要素を量化して比較するのは人間にとってとっても難しいので、プロでも意見がかなり割っている牌姿や場面も多々。ですが、明確に鳴くべきや鳴くべきではない牌姿が存在するため、鳴き判断を勉強しなければならない。

下記の条件がどちらの一つが満たす手牌は鳴くべき\citep[][pp. 36--41, p. 45, pp. 58--61]{hirasawa-naki}、

\begin{itemize}
\item 立直の打点上昇が限られた（つまり、一盃口などの門前役がついていない）
\item 愚形（または枯れている両面）を解消するため
\item 手牌の価値が満貫ある
\end{itemize}

下記の条件を全部満たす手牌は鳴きべきではない\multicitep{hirasawa-naki, p.~48; rb1, p.~216}、

\begin{itemize}
\item 安い（鳴いたら2000に過ぎない）
\item 遠い（頭がない・3副露の可能性が高い）
\item 安全牌がない
\end{itemize}


\subsubsection*{愚形解消}

\textbf{ネックである愚形が解消されたら全てを鳴く}\citep[][p.~40]{hirasawa-naki}。愚形＋両面なら両面を中盤後半までスルーする方がいい。例え手牌~\ref{mj:naki-4} が愚形＋両面の受けがあって、\mj{4s} が何巡目で来てもチーテンを取る。\mj{58p} なら9巡目までスルー。

\tehai{405667m 2267p 35s 2z}[東1局　北家　ドラ \mj{3z}][naki-4]

\textbf{ネックではない愚形を鳴かない}\citep[][p.~40]{hirasawa-naki}。特にブロックが６つあって、愚形が一つだけで、三色などの役を確定するためではないと鳴かない。よって、\ref{mj:naki-5} は \mj{7m} を鳴かないが、\ref{mj:naki-6} は打点もう十分なので \mj{7m} はチーする。

\tehai{3468m 23488p 3467s}[東1局　西家　ドラ \mj{2z}][naki-5]

\tehai{2468m 23488p 3468s}[東1局　西家　ドラ \mj{8p}][naki-6]

\subsubsection*{相手の速度} 

\textbf{相手が聴牌している（または聴牌していそう）なら副露して和了率を優先する}\citep[][p.~153]{hirasawa-naki}。上記のような中盤の終わりまでスルーの手牌で、相手がもう立直をかけている、もしくはもう両副露しているなら、手牌を鳴いて早く聴牌を取るのは得。


\subsubsection*{上家の捨て牌の傾向} 

\textbf{上家が捨てそうな牌なら鳴く}\citep[][p.~158]{hirasawa-naki}。特に上家が混一色を狙って、他の色の牌を切らなければならない状況。

手牌~\ref{mj:naki-9a} はバラバラの手牌。6巡目でマンズの混一色をしている上家が \mj{0s} を切った。この手を上がる役はピンズのイッツーだけがチー \mj{0s} により手牌の価値が高まる上上家がピンズを切ってくれる可能性が高いのでここでチー。

\tehai{11m 130689p 1346s 5z}[東1局　北家　6巡目　ドラ \mj{3m}][naki-9a]

手牌~\ref{mj:naki-9b} もバラバラの手牌。上家が \mj{5p} を切った。カン \mj{7m} を上家から鳴ける可能性が非常に低いので、ここで \mj{5p} をチーして \mj{68m} の嵌張を先に処理する。

\subsection{タンヤオ}

喰いタンは中張牌でできた搭子が全部鳴けるので作りやすい役だが、中張牌しか使えないので手牌を短くすると守備力が低下する。よって、安くて遠い喰いタンは控えよう。喰いタンの基準は\multicitep{yoteru-badnaki; tetsusenryaku, pp.~170--175}、

\begin{itemize}
\item 1000点はポンテンチーテンでない限り鳴かない
\item 3900点は愚形を全部鳴く。両面は中盤以降
\end{itemize}

\tehai{367m 234499p 3377s}[東1局　西家　5巡目　ドラ \mj{3z}][naki-tanyao-1000-3]

\subsubsection*{2000なら微妙}

2000点は微妙だが、東場の子なら1000点の基準を従ってもいいでしょう\citep[][p.~179]{tetsusenryaku}。1000点と2000点の差は大きくないから。一向聴の時、\citet[][p.~33, p.~38]{hirasawa-naki}により鳴きの基準は、

\begin{itemize}
\item 複合している門前役があれば、12巡目までスルー
\item なければ二段目で鳴くといい
\end{itemize}

手牌 \ref{mj:naki-tanyao-2000-1} のような完全一向聴の手牌はピンフで7700、少なくとも5200。一方、鳴いたら大体2000や赤で3900。よって、アガリトップ、副露している他家がない、または両面が枯れていない限り、12巡までは副露しない。

\tehai{405667m 22667p 34s}[東1局　西家　ドラ \mj{3z}][naki-tanyao-2000-1]

両面＋嵌張一向聴ならいつでも嵌張を鳴いてもいい。両面から鳴くのは9巡目から \citep[][p.~40]{hirasawa-naki}。手牌 \ref{mj:naki-tanyao-2000-2} なら \mj{4s} は絶対チーだが、\mj{58p} チーは9巡目から。

\tehai{405667m 2267p 35s 2z}[東1局　北家　ドラ \mj{3z}][naki-tanyao-2000-2]

手牌 \ref{mj:naki-tanyao-2000-3} に嵌張が二つあるが頭がない。嵌張からチーすると、頭候補が2種類減る。つまり、両面が頭になって嵌張が残る確率が上がる。よって、ここはチーしない \citep[][p.~55]{hirasawa-naki}。

\tehai{3468m 3468p 067s 34z}[東1局　西家　ドラ \mj{2z}][naki-tanyao-2000-3]

\subsubsection*{7700のドラポンは相手のケア傾向に相談}

ドラポンのメリットは打点上昇と（残りの搭子は愚形ばかりのとき）受け入れを広くすること。デメリットは警戒されやすいこと。手牌~\ref{mj:naki-tanyao-3900-1} も \ref{mj:naki-tanyao-3900-2} もポンしたら3900 $\to$ 7700で、そして \ref{mj:naki-tanyao-3900-1} は愚形だらけの手牌、\ref{mj:naki-tanyao-3900-2} も鳴いても \mj{3p} が頭になるので、メリットはデメリットより大きい。

だが、すでに満貫の手牌なら打点上昇のメリットが消える。こうなると、ドラポンの基準は受け入れの広さと警戒されやすさの比較。手牌~\ref{mj:naki-tanyao-7700-1} は~\ref{mj:naki-tanyao-3900-1} と同じ、ポンしたら受け入れが \mj{7m25p4s} から \mj{678m2p}--\mj{6p340s} になる。元々アガれなさそうな手牌なら、多少警戒されても悪くはないでしょう。相手がドラポンが入っても警戒しないなら \mj{8s} ポンは全然あり。しかし~\ref{mj:naki-tanyao-7700-2} のようなネックが \mj{4s} だけの手牌ならポンはしない\citep[][pp.~188--195]{tetsusenryaku}。

\tehai{23468m 246p 3088s 4z}[西家　4巡目　ドラ \mj{8s}][naki-tanyao-7700-1]

\tehai{23467m 334p 3088s 4z}[西家　4巡目　ドラ \mj{8s}][naki-tanyao-7700-2]

\subsection{役牌}

\textbf{役牌があればほとんどの場合は鳴く}。鳴かないの場合は次の二つ\citep[][p.~103]{hirasawa-naki}、

\begin{itemize}
\item 頭が役牌しかない
\item 鳴いたところで安くて遠い
\end{itemize}

前節のタンヤオと違って、役牌は1枚をふかしたらもう1枚の役牌が出るか出ないか全然わからないので役は確定しづらくなる。よって、役を確定するため、役牌の仕掛け基準はタンヤオより低い。


\subsubsection*{頭が役牌しかない} 

手牌~\ref{mj:naki-7a} は頭が \mj{6z} の対子しかない場合、\mj{6z} 鳴いても速度が上がってないのでスルー。2枚目が切られてもスルー\citep[][p.~104]{hirasawa-naki}。

\tehai{3457m 67p 2346s 266z}[東1局　西家　ドラ \mj{3m}][naki-7a]

逆に~\ref{mj:naki-7b} のようにポンテンができる手牌では、立直・ドラ1の打点は最低2600点、発・ドラ1の2000点からあまり高くならないので中盤に入るとポンテンをとるの方がいい\citep[][pp.~105--106]{hirasawa-naki}。

\tehai{345m 667p 23467s 66z}[東1局　西家　ドラ \mj{3m}][naki-7b]

手牌~\ref{mj:naki-7c} のように残りの搭子に愚形があるなら、役牌対子を鳴いても愚形搭子の縦引きで受け入れが増えるので鳴く。

\tehai{123m 23467p 89s 277z}[東1局　西家　5巡目　ドラ \mj{4p}][naki-7c]

役牌を鳴いた後も同じ、愚形や暗刻があり、ヘッドレスにすると受け入れが増えるので鳴いていく。手牌 \ref{mj:naki-20} から \mj{2m} を鳴いたら受け入れが \mj{6m3p} から \mj{567m234p} になる。手牌 \ref{mj:naki-21} のような両面が一つあっても頭を鳴いてもいい。手牌 \ref{mj:naki-22} のような暗刻がある手牌も鳴いた方がいい \citep[][p.~199]{hirasawa-naki}。

\subsubsection*{後付け}

「後付け」とは、聴牌の時待ちの一部しか役ができない状態を指す。例えば \ref{mj:atozuke-0a} の手牌の中の \mj{7z} は刻子ではないので役がない。\mj{7s} でロンやツモアガることはできない。\mj{7z} でロンやツモしかできない。喰いタンと後付けが認められている「アリアリ」のルールでは問題ではない。問題はその前に、手牌~\ref{mj:atozuke-0b} のように聴牌まで遠い階段、上家の切った \mj{35m2p} をチーするかしないかという仕掛けの基準。

\tehai{234m 340p 77s 77z -2'13p}[][atozuke-0a]

\tehai{246m 13340p 77s 577z}[][atozuke-0b]

もちろん \mj{13p} チーで仕掛けても \mj{7z} は多少警戒されているかもしれないが全然出ないわけでもない。警戒されている場合、もしくは絞られている場合、自分の手牌の進行が妨害されていて、他家からの立直に間に合わないと自分の手牌が縮んで守備力が落ちる。よって、\textbf{後付けの基準は手牌の価値、アガリトップ、警戒されやすさ、手牌の向聴数に基づく}\citep[][pp.~146--151]{tetsusenryaku}。要すると、

\begin{itemize}
  \item 立直がかかっている状況ではない限り全てを鳴く
  \begin{itemize}
    \item アガリトップ
    \item 南場のトップ目
    \item 満貫
  \end{itemize}
  \item トップでもない、手牌の価値も満貫でもないとき
  \begin{itemize}
    \item 2000で一向聴にならないと鳴かない
    \item 3900で両向聴にならないと鳴かない
  \end{itemize}
\end{itemize}

こう見ると、アガリトップでない限り~\ref{mj:atozuke-1} は \mj{3m3p} を鳴かない。1000点はリスクにほぼ見合わないため。

\tehai{24779m 1267p 5s 477z}[4巡目　ドラ \mj{7s}][atozuke-1]

手牌~\ref{mj:atozuke-2} のようなドラ1の手は人によって鳴けるけど、やはり聴牌までまだ遠いですね。鳴いたら一向聴になると鳴いてもいいけど、今回の牌姿は鳴いても両向聴なので、\mj{3m7m2p} は鳴かない。

\tehai{24779m 2267p 5s 477z}[4巡目　ドラ \mj{2m}][atozuke-2]

\tehai{24779m 2206p 5s 477z}[4巡目　ドラ \mj{2m}][atozuke-3]

役牌がドラになったら \mj{2'13s} のような仕掛けは相手を警戒されやすい。相手は \mj{2'13s} のような仕掛けに対してもドラ役牌をパンパン切ってくるなら鳴いてもいいでしょう。手牌~\ref{mj:atozuke-4} から \mj{2s} を鳴くのはメンツ構成に相談しよう\citep[][pp.~152--159]{tetsusenryaku}\footnote{実はプロの中でもかなり意見が割っている。副露の基準は仕掛けの警戒されやすさだけではなく、今自分の手牌の形が両面になりやすいか、鳴いた後の形はどれくらい良いか、これらも重要な要素。「鳴いても残った形は早くないのでスルー」や、「孤立牌に両面ができる可能性まだあるのでスルー」や、「愚形ばかりで \mjfn{13s} は鳴きやすくなる」など。手牌~\ref{mj:atozuke-4} でも、\mjfn{6s} のくっつきを見れば門前が近くなるが、鳴いた後両面＋両面の形で \mjfn{7z} をポンした後アガリやすい聴牌形になるので鳴きによる。多数の細かい要素をどう評価して、「どのくらい門前でいけそう」という指標を引き出して、そして鳴くか鳴かないかという選択をするのを、一般化や言語化するのはまだ難問だ。}。

\subsection{カン}

\subsubsection*{大明槓}

下記の四つの条件の中に三つあればカンする \citep[][p.~140]{kawamura-naki}、

\begin{enumerate}
\item ラス目で点数が欲しい
\item 面前にならない（役牌暗刻があるとか）
\item 鳴いたら他家より早そう
\item 少なくとも2飜ある
\end{enumerate}

2飜からカンするのは打点の上昇効率。1300が2600に（または親で2000が3900に)なっても、他家の打点上昇との比べにならないのでカンしない。

手牌 \ref{mj:kan-1} は中ドラ1、対子も全部端牌。\mj{7z} が出たらカンする \citep[][pp.~139--140]{kawamura-naki}。

\subsection{赤ドラを晒すと晒さない場面}

\textbf{通常は赤ドラを晒すべきだが、黒5を晒すのは相手に警戒されたくない場面}\citep[][p.~194]{hirasawa-naki}。例え~\ref{mj:naki-17} の副露手、\mj{5m} を晒すと相手から見える情報は「白ドラ1」ので、あまり警戒されない晒す方。
